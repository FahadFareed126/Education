LEARNSPACE — TWO-PAGE EDUCATIONAL WEBSITE

Files:
- index.html: Home page
- courses.html: Explore courses page with working category filters
- styles.css: Shared responsive styling

To preview:
1. Extract the ZIP file.
2. Open index.html in a modern web browser.
3. Use the navigation links to move between the two pages.

To customize:
- Replace LearnSpace with your school, institute, or project name.
- Edit the course titles and descriptions in courses.html.
- Adjust colors and typography in styles.css.

This is a front-end demo. It does not include user accounts, a database, or a real course enrollment system.
